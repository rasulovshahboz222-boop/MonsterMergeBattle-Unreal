MonsterMergeBattle — Project Plan

Goal

Develop a realistic third-person online battle royale for Android using Unreal Engine 5.

Phase 1 — Foundation

- Create the Unreal Engine project on a compatible computer or cloud workstation.
- Set up source control.
- Configure Android support.
- Keep the existing Godot project unchanged.

Phase 2 — Playable Prototype

- Third-person character and camera.
- Mobile movement and aiming controls.
- Small test map.
- Health, damage, and one test weapon.
- Gunfire, reload, and impact audio.

Phase 3 — Vehicles and World

- Add a drivable vehicle.
- Implement acceleration, steering, and braking.
- Add engine and tire audio.
- Expand the map after performance testing.

Phase 4 — Multiplayer

- Build a server-authoritative multiplayer prototype.
- Test with 2–4 players first.
- Add lobby, loot, elimination, and victory systems.
- Target 50 players only after dedicated-server and load testing.

Phase 5 — Android Release

- Optimize graphics for mobile devices.
- Test on real Android phones.
- Package and test the Android build.
- Publish a project website with progress and download information.

Important

GitHub stores the project files; it does not by itself run Unreal Engine or host real-time multiplayer matches. The game and APK are not built yet.
