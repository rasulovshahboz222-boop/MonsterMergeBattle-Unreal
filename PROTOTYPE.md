MonsterMergeBattle — First Prototype

Objective

Create the first small playable third-person prototype in Unreal Engine 5.

Prototype Features

- Third-person character and follow camera
- Walking, running, and jumping
- Basic mobile touch controls
- Small outdoor test map
- One test weapon with firing and reloading
- Gunshot and impact audio
- Health and damage system
- Performance settings for Android

Development Order

1. Create the Unreal Engine project.
2. Add the third-person character.
3. Build the small test map.
4. Add the weapon and audio.
5. Test movement and combat.
6. Optimize for Android.
7. Add vehicles and multiplayer in later milestones.

Acceptance Criteria

- Character movement and camera work correctly.
- Weapon firing and reload work.
- Audio plays at appropriate events.
- Prototype runs smoothly on the target device.
- Test results are documented.

Status

Planning only. The prototype has not been built or tested.
