MonsterMergeBattle

About the Game

MonsterMergeBattle is a planned third-person online battle royale game for Android, developed with Unreal Engine 5.

Planned Features

- Third-person camera and character movement
- Mobile touch controls
- Large open-world map
- Guns, ammunition, health, and loot
- Drivable cars and other vehicles
- Online multiplayer battles
- Target of up to 50 players per match
- Shrinking safe zone
- Lobby, elimination, and victory system
- Android APK release
- Project website

Development Roadmap

1. Create the Unreal Engine 5 project.
2. Build a basic playable character and camera.
3. Add mobile controls.
4. Create a small test map.
5. Add weapons and health.
6. Add vehicles.
7. Build and test multiplayer with a few players.
8. Add the battle royale system.
9. Optimize and test toward 50 players.
10. Package and test the Android APK.
11. Publish the project website.

Important Notes

- This repository currently contains project documentation, not a completed game or APK.
- Unreal Engine and the Android build tools will be needed to build the real game.
- The 50-player target must be verified through multiplayer testing.
- The existing Godot project must remain separate and unchanged.
