MonsterMergeBattle — Game Design

1. Game Overview

- Genre: 3D third-person online battle royale
- Engine: Unreal Engine 5
- Platform: Android
- Visual target: high realism, optimized for mobile
- Match target: up to 50 players, subject to server and performance testing

2. Player

- Third-person camera
- Walking, running, jumping, crouching
- Mobile touch controls
- Health and damage system
- Weapon aiming and reloading

3. Weapons and Audio

- Original weapon models and animations
- Gunshot, reload, impact, and distant-shot sounds
- Footsteps and environmental audio
- Muzzle flashes and visual effects
- Audio must be optimized for mobile performance

4. Vehicles

- Enter and exit vehicles
- Driving, steering, braking, and acceleration
- Engine and tire sounds
- Vehicle damage can be added in a later milestone

5. World

- Outdoor terrain with hills, roads, buildings, and vegetation
- Loot and ammunition pickup points
- Daylight and shadows
- Start with a small test map before building a larger world

6. Battle Royale

- Lobby and match start
- Loot collection
- Shrinking safe zone
- Player elimination
- Last player or team standing wins

7. Multiplayer

- Start testing with 2–4 players
- Use a server-authoritative design
- Increase player count only after network and server tests
- Goal: 50 players per match; not yet verified

8. Android Performance

- Scalable graphics settings
- Touch-friendly UI
- Optimize textures, shadows, effects, and draw calls
- Test on real Android devices before release

9. Milestones

1. Unreal Engine project setup
2. Third-person movement and camera
3. Small playable test map
4. Weapons, health, and sound
5. Vehicle prototype
6. Multiplayer prototype
7. Battle royale systems
8. Performance and server testing
9. Android package and device testing
10. Project website

Current Status

This document describes the intended design. The Unreal Engine game and Android APK have not yet been built.
